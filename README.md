This is a simple platformer game created in Godot Engine. If you would like to play click this link to view the demo: https://sovyrn.itch.io/left-and-right-simulator-part-ii . 

How to play:

You may use left arrow, right arrow and up arrow to move.
You can also use W, A, and D to move.

Look around to find the tips hidden in the game!

Enjoy!
